# DemoCompany

Requiere Python 3.10 o superior y conexión a Internet.

Desde la carpeta raíz del proyecto:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python desafio/main.py
```

Genera `contratistas.csv` y registra la ejecución en `proceso.log`.
Para volver a ejecutarlo: `.venv/bin/python desafio/main.py`.

La configuración de `.env` es opcional. Hay un ejemplo en `.env.example`.
